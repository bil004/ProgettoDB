# ProgettoDB

Progetto del corso di BD, anno 2025/2026

Descrizione
Questo progetto realizza un database relazionale per la gestione delle informazioni sui parchi nazionali. L'obiettivo è modellare in modo completo entità come parchi, aree protette, sentieri/tragitti, punti di accesso, visitatori e feedback, e fornire uno schema ER e la corrispondente implementazione relazionale.

Artefatti inclusi:
- la specifica del progetto e i requisiti (file PDF nella root);
- il diagramma ER nella cartella `ER/` (`ER_DEFINITIVO_t.er`) e lo schema relazionale in `ER/Schema_Relazionale.md`;
- gli script SQL per creare e popolare il database in `SQL/scriptProject.sql`.

Deliverable tipici: diagramma ER, schema relazionale, script SQL di creazione e popolamento, e una serie di query di esempio per supportare le analisi sui dati dei parchi.

Per iniziare: aprire `SQL/scriptProject.sql` e eseguire gli statement DDL/DML sul vostro server PostgreSQL/MySQL a scelta; il file ER contiene il modello concettuale usato per derivare lo schema relazionale.
